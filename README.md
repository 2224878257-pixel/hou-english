# 侯同学英语

专为个人学习制作的轻量英语学习网页。30 天 A1 基础句子课程，听力、慢速播放、理解测验、语音识别（浏览器支持时）、跟读录音、拼写自测、错题记录、数据导入导出。**不需要安装依赖或 API Key。**

## GitHub Pages 部署

1. 在 GitHub 新建一个 **Public** 仓库，例如 `hou-english`。
2. 将本目录的 `index.html`、`icon.svg`、`manifest.webmanifest`、`sw.js`、`README.md` 上传到仓库**根目录**并提交到 `main` 分支（不要只上传压缩包）。
3. 打开仓库 **Settings → Pages → Build and deployment → Source: Deploy from a branch**。
4. 选择 `main`、`/(root)`，点击 **Save**。
5. 发布后访问 `https://<你的 GitHub 用户名>.github.io/hou-english/`。若仓库名不同，替换路径。也可以在 Pages 设置页点击 Visit site 获取准确网址。
6. 手机用浏览器访问同一网址；可使用浏览器“添加到主屏幕”。

## 功能与限制

- 课程为预设 30 天入门课程，每天提供一个核心句子，建议结合复习练习 20–30 分钟；这不是完整的 30 天教学体系，也不提供真正的 AI 对话。
- 语音播放采用浏览器语音合成；口语识别使用浏览器 Web Speech API；部分手机浏览器不支持识别或需要网络服务。
- 录音仅在当前会话中供回听，不上传、不长期保存。麦克风需允许权限，建议通过 HTTPS 使用。
- 课程和网页外壳可离线缓存，但语音识别不保证离线可用。
- 学习数据存储于浏览器 localStorage，换手机/换浏览器/清浏览器数据不会自动同步。通过“学习记录 → 导出数据 / 导入数据”手动迁移。
- GitHub Pages 是静态公开网站。页面本身公开，但本工具不会自动公开学习数据；不要在仓库上传包含个人信息的学习数据备份。
- 每步的“完成”由用户主动确认，不代表已通过测评；语音识别结果不是专业发音评分。

## 本地预览

可直接打开 `index.html` 学习部分功能。建议使用 `python -m http.server 8000` 启动本地服务器，打开 `http://localhost:8000/`。录音和语音识别建议在 HTTPS 网页测试。
