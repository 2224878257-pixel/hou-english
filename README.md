# 侯同学英语 v1.2（个人英语练习）

GitHub Pages 可用的纯静态英语学习网站。手机、电脑浏览器访问。无需账号、服务器或 API Key。

## 部署到已有 GitHub 仓库

1. 解压 ZIP。**不要将 ZIP 本身上传后期待 GitHub 自动解压**。
2. 将 `index.html`、`sw.js`、`manifest.webmanifest`、`icon.svg` 和整个 `audio/` 文件夹上传到仓库根目录，覆盖旧文件。
3. 等待 GitHub Pages 重新部署；若手机还是旧版，请退出已安装的桌面网站、重新打开或清理该站点缓存。

## 学习机制

- 每课一句核心表达，按「听 → 选择意思 → 跟读 → 回忆输入」四个阶段学习；测试通过才能进入下一步。
- 30 课是基础练习素材，不等于系统化的英语课程；每天建议至少 15 分钟，复习在「复习本」。
- 选择/拼写错误记入复习本，次日进行复习；复习成功后逐渐延长间隔。
- 内置本地 MP3 朗读文件，点击即播，不依赖浏览器的语音合成服务。
- 跟读录音只保留在浏览器当前会话中；不可保证所有手机浏览器都有麦克风录音权限。
- 所有学习记录保存在当前设备 localStorage，不会自动在手机和电脑之间同步。备份和导入功能用于手动迁移。
- 首次进入会尝试迁移 v1.1 的课程完成记录和错题记录；不会覆盖新的 v1.2 记录。

## 局限

网页没有 AI 语音对话或自动发音评分。每课仅一个重点句子，仍建议结合更多真实英语听力材料；对语音的自评由学习者自行完成。音频是离线合成的备用声音，不建议拿来作为唯一的发音标杆。公开的 GitHub 仓库中不要上传学习数据备份。
